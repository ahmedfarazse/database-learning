# Database Relationships

This folder covers how different tables interact and connect with each other in a relational database.

Relationships are the core of "Relational" databases. They define how data in one table is linked to data in another table using Primary and Foreign Keys.

---

## Purpose

* Understand the three main types of database relationships.
* Learn when to use One-to-One (1:1), One-to-Many (1:N), and Many-to-Many (M:N).
* Understand the concept of a Junction Table (Associative Entity) for Many-to-Many relationships.
