# ORDER BY and GROUP BY

This folder explains how to sort data and how to group rows together to create summaries using SQL.

Retrieving data is only the first step. Presenting it in a meaningful order or summarizing it (like getting total counts) is crucial for reporting and user interfaces.

---

## Purpose

* Understand how to sort data using `ORDER BY`.
* Learn the difference between `ASC` (Ascending) and `DESC` (Descending).
* Understand how to summarize data using `GROUP BY`.
* Learn about Aggregate Functions like `COUNT()`, `SUM()`, `MAX()`, and `MIN()`.
