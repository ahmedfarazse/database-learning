# SELECT and WHERE (Filtering Data)

This folder covers how to retrieve specific data from a database using the `SELECT` statement combined with the `WHERE` clause.

In real world applications, tables often contain millions of records. We rarely need all of them at once. Filtering data is a critical skill for database querying.

---

## Purpose

* Understand how to choose specific columns using `SELECT`.
* Understand how to filter specific rows using `WHERE`.
* Learn common comparison operators (`=`, `>`, `<`, etc.).
* Learn logical operators (`AND`, `OR`, `IN`, `LIKE`).
