# Database Indexes

This folder covers Database Indexes, a powerful optimization tool used to speed up data retrieval operations.

Just like a book's index helps you find a topic quickly without reading every page, a database index helps the SQL engine find data without scanning the entire table.

---

## Purpose

* Understand what an Index is and how it works under the hood.
* Learn the SQL commands to Create and Drop indexes.
* Understand the trade-offs: faster read speeds vs. slower write speeds.
* Learn the best practices of when to use and when NOT to use indexes.
