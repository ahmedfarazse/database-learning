# Database Constraints

This folder covers Database Constraints, which are the rules applied to columns in a table to ensure data accuracy, validity, and reliability.

Constraints are the first line of defense against bad data entering your database.

---

## Purpose

* Understand what SQL constraints are and why they are necessary.
* Learn the 6 most common constraints: `NOT NULL`, `UNIQUE`, `PRIMARY KEY`, `FOREIGN KEY`, `CHECK`, and `DEFAULT`.
* Understand how to apply these rules when creating a table.
