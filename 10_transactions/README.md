# Database Transactions & ACID Properties

This folder covers Database Transactions, a crucial concept for maintaining data integrity and handling errors gracefully in a relational database.

Transactions ensure that complex operations involving multiple steps are treated as a single, indivisible unit of work.

---

## Purpose

* Understand what a database transaction is.
* Learn the SQL commands: `BEGIN`, `COMMIT`, and `ROLLBACK`.
* Learn the importance of the ACID properties in database design.
* Understand how to prevent partial data updates during system failures.
