# Database Normalization

This folder introduces the concept of Database Normalization, a critical design process used to organize tables and columns in a relational database.

Properly normalized databases reduce data redundancy, ensure data integrity, and prevent strange errors when updating or deleting records.

---

## Purpose

* Understand what Database Normalization is.
* Learn the dangers of data redundancy and update anomalies.
* Understand the basic principles of the first three Normal Forms (1NF, 2NF, 3NF).
* Learn how to identify poorly designed tables and how to fix them by splitting data into related tables.
