# CRUD Operations

This folder covers the four fundamental operations used to manage data in any relational database: Create, Read, Update, and Delete (CRUD).

Understanding CRUD is essential because almost every feature in a software application relies on these four basic database actions.

---

## Purpose

* Understand the concept of CRUD.
* Learn the corresponding SQL commands: `INSERT`, `SELECT`, `UPDATE`, and `DELETE`.
* Learn how to write these basic SQL queries to manipulate table data.
* Understand the critical importance of the `WHERE` clause when updating or deleting data.
