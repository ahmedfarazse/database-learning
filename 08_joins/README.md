# Database JOINs

This folder covers SQL JOINs, which are used to combine rows from two or more tables based on a related column between them.

Since relational databases store different types of data in separate tables, JOINs are the most essential tool for bringing that data back together for reports and user interfaces.

---

## Purpose

* Understand the concept of joining tables using Foreign Keys.
* Learn the differences between the four main types of JOINs.
* Practice writing queries using `INNER JOIN`, `LEFT JOIN`, `RIGHT JOIN`, and `FULL JOIN`.
